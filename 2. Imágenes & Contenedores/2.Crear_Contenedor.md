
## `docker run`

Este comando crea y arranca un contenedor a partir de una imagen. 

La sintaxis básica es `docker run [opciones] <imagen>:<tag>` 

En mi caso, usé la imagen `docker/getting-started:latest` que bajé antes, la ejecuté en segundo plano (`-d`) y redirigí el puerto 80 del contenedor al puerto 8965 de mi máquina local (`-p 8965:80`). Así puedo acceder al servicio web que corre dentro del contenedor desde mi navegador.

**Ejemplo de comando:**
```bash
docker run -d -p 8965:80 docker/getting-started:latest
```

**Salida esperada (devuelve el ID del contenedor recién creado):**
```
2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f
```

> 🟢 **Tip:** el ID largo que aparece es el identificador único del contenedor. Si pierdo la terminal, puedo recuperarlo con `docker ps`.

## `docker ps`

`docker ps` me muestra los contenedores que están actualmente en ejecución. Es útil para verificar que mi contenedor arrancó bien y para ver qué puertos tiene mapeados. En la columna `PORTS` puedo confirmar que el forwarding está funcionando: `0.0.0.0:8965->80/tcp` significa que todo el tráfico hacia el puerto 8965 de mi máquina va al puerto 80 del contenedor.

**Ejemplo de comando:**
```bash
docker ps
```

**Salida esperada:**
```
CONTAINER ID   IMAGE                           COMMAND                  CREATED         STATUS         PORTS                  NAMES
2f3a4b5c6d7e   docker/getting-started:latest   "/docker-entrypoint.…"   5 seconds ago   Up 4 seconds   0.0.0.0:8965->80/tcp   naughty_galileo
```

> 📡 **Nota:** el nombre `naughty_galileo` lo asigna Docker automáticamente si no le pongo uno con `--name`. Es random pero gracioso. Si quiero un nombre fijo, uso `--name mi_cont`.

## Verificación en navegador

Después de correr el comando, abrí `http://localhost:8965` en mi navegador y debería ver una página web con el tutorial de Docker. Esto confirma que el contenedor está sirviendo tráfico HTTP correctamente.

**Pasos para la lección (resumen):**
1. `docker run -d -p 8965:80 docker/getting-started:latest` — arranco el contenedor.
2. `docker ps` — verifico que esté corriendo y que el puerto esté mapeado.
3. Abro `http://localhost:8965` en el navegador para ver la página.
