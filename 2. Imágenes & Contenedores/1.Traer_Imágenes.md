
## `docker pull` 

Acá bajé la imagen `docker/getting-started` que es un tutorial interactivo de Docker. Es una imagen oficial mantenida por Docker, así que no necesita namespace (es como si tuviera `library/` adelante). El comando la descarga capa por capa y la guarda en mi caché local.

**Ejemplo de comando:**
```bash
docker pull docker/getting-started
```

## `docker images`

Este comando me lista todas las imágenes que tengo guardadas localmente en mi máquina. Muestra el repositorio, el tag, el ID, la fecha de creación y el tamaño. Es útil para ver qué tengo disponible sin tener que descargar de nuevo. Después de hacer el `pull`, debería aparecer `docker/getting-started` en la lista.

**Ejemplo de comando:**
```bash
docker images
```

**Salida esperada (al menos debería contener la imagen que bajé):**
```
REPOSITORY                TAG       IMAGE ID       CREATED        SIZE
docker/getting-started    latest    1f2a3b4c5d6e   2 weeks ago    45.3MB
hello-world               latest    f1a2b3c4d5e6   3 months ago   13.3kB
nginx                     1.25      8a9b0c1d2e3f   4 months ago   187MB
```

> 📦 **Tip:** si ves `docker/getting-started` en la lista, significa que ya la tengo localmente y puedo usarla para crear contenedores sin necesidad de descargarla otra vez. También la puedo ver en el tab "Images" del Docker Desktop.


**Pasos para la lección (resumen):**
1. `docker pull docker/getting-started` — baja la imagen de ejemplo.
2. `docker images` — verifico que esté en mi lista local.
3. Abrir Docker Desktop y chequear que aparezca en la pestaña "Images".
