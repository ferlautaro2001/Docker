## Dockerizando el servidor Go

Ahora que el servidor funciona localmente, voy a crear una imagen Docker para ejecutarlo dentro de un contenedor. El proceso es: crear un `Dockerfile`, copiar el binario compilado y definir el comando de ejecución.

---

### 1. Crear el `Dockerfile`

En el directorio raíz del proyecto creo un archivo `Dockerfile` (sin extensión):

```dockerfile
FROM debian:stable-slim

COPY goserver /bin/goserver

CMD ["/bin/goserver"]
```

> 📝 **Explicación línea por línea:**
> - `FROM debian:stable-slim` — usa una imagen base liviana de Debian.
> - `COPY goserver /bin/goserver` — copia el binario compilado al contenedor en `/bin/goserver`.
> - `CMD ["/bin/goserver"]` — ejecuta el servidor cuando el contenedor arranca.

> ⚠️ **Importante:** si el nombre de mi binario es diferente (ej. `myapp`), cambio `goserver` por ese nombre.

---

### 2. Recompilar el binario para Linux

Si compilé el servidor en mi máquina local (ej. macOS o Windows), el binario puede no funcionar dentro del contenedor Linux. Debo recompilarlo para `linux/amd64`:

```bash
GOOS=linux GOARCH=amd64 go build -o goserver
```

**Salida esperada:** no hay salida, pero el binario `goserver` ahora es compatible con Linux.

> 💡 **¿Qué hacen estas variables?**
> - `GOOS=linux` — compila para el sistema operativo Linux.
> - `GOARCH=amd64` — compila para arquitectura de 64 bits.

---

### 3. Construir la imagen Docker

```bash
docker build . -t goserver:latest
```

**Salida esperada:**
```

 => [internal] load build definition from Dockerfile
 => => transferring dockerfile: 108B
 => [internal] load .dockerignore
 => => transferring context: 2B
 => [1/2] FROM docker.io/library/debian:stable-slim
 => [2/2] COPY goserver /bin/goserver
 => exporting to image
 => => exporting layers
 => => writing image sha256:2f3a4b5c6d7e...
 => => naming to docker.io/library/goserver:latest
```

- `.` — el contexto de construcción (directorio actual).
- `-t goserver:latest` — etiqueto la imagen como `goserver:latest`.

---

### 4. Verificar que la imagen se creó

```bash
docker images
```

**Salida esperada:**
```
REPOSITORY    TAG       IMAGE ID       CREATED              SIZE
goserver      latest    2f3a4b5c6d7e   About a minute ago   55.3MB
debian        stable-slim  8a9b0c1d2e3f   2 weeks ago          55.3MB
```

---

### 5. Ejecutar el contenedor

```bash
docker run -p 8010:8010 goserver
```

**Salida esperada:**
```
server started on 8010
```

> 📝 **Nota:** el contenedor se queda ejecutando en la terminal (modo foreground). El puerto 8010 del contenedor está mapeado al puerto 8010 del host (`-p 8010:8010`).

---

### 6. Probar el servidor desde el host

```bash
curl http://localhost:8010/
```

**Salida esperada:**
```html
<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
```

> ✅ **¡El servidor funciona dentro de Docker!**

---

### 7. Probar en el navegador

Abro `http://localhost:8010/` en el navegador. Debería ver:

```
Hello from Docker! I'm a Go server.
```

> 🌐 **Nota:** el servidor está corriendo dentro del contenedor, pero lo accedo desde el host gracias al forwarding de puertos.

---

### 8. Detener el contenedor

Presiono `Ctrl+C` en la terminal donde está corriendo el contenedor.

**Salida esperada:**
```
^C
```

> 🛑 **Nota:** el contenedor se detiene y vuelvo al prompt de la terminal.

---

### 9. Verificar que el contenedor se detuvo

```bash
docker ps -a
```

**Salida esperada:**
```
CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS                      PORTS     NAMES
3f4a5b6c7d8e   goserver      "/bin/goserver"          2 minutes ago   Exited (0) 1 minute ago               intelligent_galileo
```

> 📋 **Nota:** el contenedor aparece con `Exited (0)`, indicando que terminó correctamente al presionar Ctrl+C.

**Pasos para la lección (resumen):**
1. Creo `Dockerfile` con `FROM debian:stable-slim`, `COPY goserver /bin/goserver`, `CMD ["/bin/goserver"]`.
2. Recompilo el binario: `GOOS=linux GOARCH=amd64 go build -o goserver`.
3. `docker build . -t goserver:latest` — construyo la imagen.
4. `docker run -p 8010:8010 goserver` — ejecuto el contenedor.
5. `curl http://localhost:8010/` — verifico que responde.
6. `Ctrl+C` — detengo el contenedor.
