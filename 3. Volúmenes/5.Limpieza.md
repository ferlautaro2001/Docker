## Limpiar todo

Después de tantas pruebas, tengo contenedores detenidos y volúmenes que ya no necesito. Limpiarlos libera espacio y mantiene mi sistema ordenado.

---

### Paso 1: ver todos los contenedores (incluso los detenidos)

```bash
docker ps -a
```

**Salida esperada (con varios contenedores de Ghost y getting-started):**
```
CONTAINER ID   IMAGE                           COMMAND                  CREATED          STATUS                      PORTS     NAMES
7a8b9c0d1e2f   ghost:latest                    "docker-entrypoint.s…"   15 minutes ago   Up 15 minutes               0.0.0.0:3001->2368/tcp   ghost_container
f1a2b3c4d5e6   docker/getting-started:latest   "/docker-entrypoint.…"   20 minutes ago   Exited (0) 15 minutes ago             naughty_galileo

```

> 📋 **Nota:** veo varios contenedores, algunos detenidos, otros corriendo. Todos ocupan espacio.

---

### Paso 2: eliminar todos los contenedores

Puedo eliminarlos uno por uno:

```bash
docker rm 7a8b9c0d1e2f f1a2b3c4d5e6 3a4b5c6d7e8f 2f3a4b5c6d7e
```

**Salida esperada (cada ID aparece en una línea):**
```
7a8b9c0d1e2f
f1a2b3c4d5e6
3a4b5c6d7e8f
2f3a4b5c6d7e
```

> 💡 **Tip rápido:** `docker rm $(docker ps -aq)` elimina **todos** los contenedores, tanto en ejecución como detenidos, en un solo comando.

> ⚠️ **Advertencia:** `docker rm` solo funciona con contenedores detenidos. Si alguno está corriendo, primero lo detengo con `docker stop` o uso `-f` para forzar.

---

### Paso 3: ver todos los volúmenes

```bash
docker volume ls
```

**Salida esperada:**
```
DRIVER    VOLUME NAME
local     ghost-vol
```

---

### Paso 4: eliminar el volumen

```bash
docker volume rm ghost-vol
```

**Salida esperada:**
```
ghost-vol
```

> 💡 **Tip rápido:** `docker volume rm $(docker volume ls -q)` elimina **todos** los volúmenes en un solo comando.

> ⚠️ **Importante:** Docker no permite eliminar un volumen mientras algún contenedor lo esté usando. Si veo un error `volume ghost-vol is in use`, significa que todavía hay un contenedor (activo o detenido) montado en ese volumen.

---

### Verificación final

Para confirmar que limpié todo:

```bash
docker ps -a
```

**Salida esperada (vacía o solo contenedores de sistema):**
```
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
```

```bash
docker volume ls
```

**Salida esperada (vacía):**
```
DRIVER    VOLUME NAME
```

> 🧹 **Conclusión:** mi sistema Docker quedó limpio, sin contenedores ni volúmenes residuales. Todo el espacio que ocupaban los recursos de prueba fue liberado.

**Pasos para la lección (resumen):**
1. `docker ps -a` — veo todos los contenedores.
2. `docker rm <ID1> <ID2> ...` o `docker rm $(docker ps -aq)` — los elimino.
3. `docker volume ls` — veo los volúmenes.
4. `docker volume rm ghost-vol` o `docker volume rm $(docker volume ls -q)` — elimino el volumen.
