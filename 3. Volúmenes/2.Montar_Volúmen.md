## Creando un sitio web con Ghost

En esta lección voy a poner en práctica lo que aprendí sobre volúmenes. Ghost es un CMS de blogging que necesita persistir datos (posts, configuraciones, usuarios). Usando el volumen `ghost-vol` que creé antes, puedo montarlo en el contenedor y asegurarme de que todo lo que escriba se guarde fuera del contenedor.

**Comando para ejecutar Ghost:**
```bash
docker run -d -p 3001:2368 -v ghost-vol:/var/lib/ghost ghost:latest
```

- `-d` — en segundo plano.
- `-p 3001:2368` — mapeo el puerto 2368 interno de Ghost al 3001 de mi host.
- `-v ghost-vol:/var/lib/ghost` — monto el volumen `ghost-vol` en la ruta donde Ghost guarda sus datos.

---

### Configurar el blog

Después de ejecutar el comando, abro http://localhost:3001/ghost/#/setup y creo un sitio nuevo con estos datos:

- **Title:** "My Docker Blog"
- **Name:** (mi nombre)
- **Email:** docker@test.com
- **Password:** correct horse

Luego creo un nuevo post y lo publico:
- **Título:** "I Love Docker"
- **Contenido:** "Truly I do."

Cuando termino, puedo ver el post publicado en la homepage: http://localhost:3001/

---

## Verificación

Abro http://localhost:3001/ y debería ver mi post publicado:

**Contenido esperado en la página:**
```
I Love Docker
Truly I do.
```

> 📝 **Nota importante:** El título y el contenido deben coincidir exactamente en mayúsculas, minúsculas y puntuación. "Truly I do." termina con un punto.

---

## ¿Qué pasa con el volumen?

Si detengo y elimino este contenedor:
```bash
docker stop <container_id>
docker rm <container_id>
```

Y luego arranco uno nuevo con el mismo volumen montado:
```bash
docker run -d -p 3001:2368 -v ghost-vol:/var/lib/ghost ghost:latest
```

El blog sigue teniendo mi post. Ghost lo guardó en `/var/lib/ghost`, y como esa ruta está montada en el volumen, los datos sobreviven al contenedor.

> 🧠 **Conclusión:** el volumen `ghost-vol` contiene ahora toda la configuración, usuarios y posts del blog. Si borro el contenedor y creo otro, el contenido sigue ahí.

**Pasos para la lección (resumen):**
1. `docker run -d -p 3001:2368 -v ghost-vol:/var/lib/ghost ghost:latest` — arranco Ghost con el volumen.
2. Configuro el blog en http://localhost:3001/ghost/#/setup.
3. Creo y publico un post con título "I Love Docker" y contenido "Truly I do.".
4. Verifico en http://localhost:3001/ que veo el post.
