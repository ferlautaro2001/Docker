## Servidores de aplicación con Caddy

En esta lección voy a levantar dos servidores web simples usando **Caddy**, un servidor web moderno escrito en Go. Cada uno servirá una página HTML diferente para que luego pueda ver cómo el balanceador de carga distribuye el tráfico entre ellos.

### 1. Descargar la imagen de Caddy

```bash
docker pull caddy
```

**Salida esperada:**
```
Using default tag: latest
latest: Pulling from library/caddy
Digest: sha256:2f3a4b5c6d7e...
Status: Downloaded newer image for caddy:latest
docker.io/library/caddy:latest
```

---

### 2. Crear los archivos HTML

Primero creo dos archivos HTML simples en mi directorio de trabajo:

**`index1.html`:**
```html
<html>
  <body>
    <h1>Hello from server 1</h1>
  </body>
</html>
```

**`index2.html`:**
```html
<html>
  <body>
    <h1>Hello from server 2</h1>
  </body>
</html>
```

> 💡 **Tip:** uso `$PWD` en Linux/macOS o `%cd%` en Windows para referenciar el directorio actual.

---

### 3. Levantar el servidor 1

```bash
docker run -d -p 8881:80 -v $PWD/index1.html:/usr/share/caddy/index.html caddy
```

**Salida esperada:**
```
2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f
```

- `-d` — ejecuta en segundo plano.
- `-p 8881:80` — mapea el puerto 80 del contenedor al 8881 de mi máquina.
- `-v $PWD/index1.html:/usr/share/caddy/index.html` — monta mi archivo HTML en la ruta donde Caddy busca el archivo por defecto.

---

### 4. Levantar el servidor 2

```bash
docker run -d -p 8882:80 -v $PWD/index2.html:/usr/share/caddy/index.html caddy
```

**Salida esperada:**
```
3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3
```

- `-p 8882:80` — mapea el puerto 80 al 8882 del host.

---

### 5. Verificar los servidores

```bash
curl http://localhost:8881
```

**Salida esperada:**
```html
<html>
  <body>
    <h1>Hello from server 1</h1>
  </body>
</html>
```

```bash
curl http://localhost:8882
```

**Salida esperada:**
```html
<html>
  <body>
    <h1>Hello from server 2</h1>
  </body>
</html>
```

> 🌐 **Nota:** si abro `http://localhost:8881` en mi navegador, veo "Hello from server 1". Si abro `http://localhost:8882`, veo "Hello from server 2".

---

### 6. Ver los contenedores en ejecución

```bash
docker ps
```

**Salida esperada:**
```
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS                  NAMES
2f3a4b5c6d7e   caddy     "caddy run --config …"   5 seconds ago   Up 4 seconds   0.0.0.0:8881->80/tcp   brave_bose
3a4b5c6d7e8f   caddy     "caddy run --config …"   4 seconds ago   Up 3 seconds   0.0.0.0:8882->80/tcp   hungry_hawking
```

> 📋 **Nota:** tengo dos contenedores Caddy corriendo, cada uno en su propio puerto y sirviendo una página diferente.


**Pasos para la lección (resumen):**
1. `docker pull caddy` — descargo la imagen oficial de Caddy.
2. Creo `index1.html` y `index2.html` con el contenido de los textos.
3. `docker run -d -p 8881:80 -v $PWD/index1.html:/usr/share/caddy/index.html caddy` — arranco el servidor 1.
4. `docker run -d -p 8882:80 -v $PWD/index2.html:/usr/share/caddy/index.html caddy` — arranco el servidor 2.
5. Verifico en `http://localhost:8881` y `http://localhost:8882`.
