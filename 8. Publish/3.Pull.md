## Eliminar y descargar desde Docker Hub

Ahora que mi imagen está publicada en Docker Hub, puedo eliminar la copia local y volver a descargarla. Esto demuestra que las imágenes en la nube son portables: puedo recuperarlas desde cualquier máquina que tenga Docker.

---

### 1. Eliminar la imagen local

```bash
docker image rm tu-usuario/goserver
```

**Salida esperada:**
```
Untagged: tu-usuario/goserver:latest
Untagged: tu-usuario/goserver@sha256:2f3a4b5c6d7e...
Deleted: sha256:2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f
```

> 🗑️ **Nota:** la imagen se elimina de mi almacenamiento local. Ya no puedo ejecutarla sin descargarla nuevamente.

---

### 2. Verificar que la imagen ya no está

```bash
docker images | grep goserver
```

**Salida esperada:** (vacía, no debería mostrar nada)

---

### 3. Descargar la imagen desde Docker Hub

```bash
docker pull tu-usuario/goserver
```

**Salida esperada:**
```
Using default tag: latest
latest: Pulling from tu-usuario/goserver
2f3a4b5c6d7e: Pull complete 
3a4b5c6d7e8f: Pull complete 
Digest: sha256:2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f
Status: Downloaded newer image for tu-usuario/goserver:latest
docker.io/tu-usuario/goserver:latest
```

> 📥 **Nota:** `docker pull` descarga la imagen desde el registro (Docker Hub) y la guarda localmente.

---

### 4. Verificar que la imagen está de vuelta

```bash
docker images | grep goserver
```

**Salida esperada:**
```
tu-usuario/goserver   latest    2f3a4b5c6d7e   2 minutes ago   55.3MB
```

---

### 5. Ejecutar el contenedor para confirmar que funciona

```bash
docker run -p 8991:8991 tu-usuario/goserver
```

**Salida esperada:**
```
server started on 8991
```

> ✅ **¡Funciona!** La imagen descargada desde Docker Hub es idéntica a la que subí.

---

### 6. Probar el servidor

```bash
curl http://localhost:8991/
```

**Salida esperada:**
```html
<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
```

---

### 7. Detener el contenedor

Presiono `Ctrl+C` en la terminal donde está corriendo el contenedor.

---

### ¿Por qué es útil esto?

- **Portabilidad** — puedo ejecutar mi imagen en cualquier máquina con Docker.
- **Respaldo** — si pierdo mi máquina local, la imagen está segura en la nube.
- **Compartir** — otros desarrolladores pueden descargar mi imagen y ejecutarla.
- **CI/CD** — puedo construir imágenes en un pipeline y desplegarlas automáticamente.

> 🧠 **Conclusión:** Docker Hub (y otros registros) actúan como un "GitHub de imágenes", permitiendo almacenar, versionar y distribuir imágenes de contenedores de forma centralizada.

**Pasos para la lección (resumen):**
1. `docker image rm tu-usuario/goserver` — elimino la imagen local.
2. `docker pull tu-usuario/goserver` — la descargo desde Docker Hub.
3. `docker run -p 8991:8991 tu-usuario/goserver` — ejecuto el contenedor.
4. `curl http://localhost:8991/` — verifico que funciona.
5. `Ctrl+C` — detengo el contenedor.
