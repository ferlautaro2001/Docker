## El panorama general: Docker en el ciclo de vida del desarrollo

Docker no es solo una herramienta para ejecutar contenedores localmente. Es una pieza clave en los **pipelines de CI/CD** y en el despliegue de aplicaciones en producción. Entender cómo encaja en el flujo de trabajo de una empresa moderna es fundamental para cualquier desarrollador o ingeniero de plataformas.

---

### Flujo de despliegue típico

```
1. El desarrollador escribe nuevo código
                ↓
2. Hace commit y push a GitHub
                ↓
3. Abre un Pull Request
                ↓
4. Un compañero revisa y aprueba el PR
                ↓
5. Se hace merge a la rama principal
                ↓
6. Un script automatizado (GitHub Actions, GitLab CI, etc.) se activa
                ↓
7. El script compila el código (si es necesario)
                ↓
8. Construye una nueva imagen Docker
                ↓
9. Sube la imagen a un registro (Docker Hub, ECR, etc.)
                ↓
10. El orquestador (Kubernetes, Docker Swarm, etc.) detecta la nueva versión
                ↓
11. Descarga la nueva imagen
                ↓
12. Reemplaza los contenedores antiguos por los nuevos
```

---

### Componentes del pipeline

| Paso | Herramientas posibles |
|------|----------------------|
| Control de versiones | GitHub, GitLab, Bitbucket |
| CI/CD | GitHub Actions, GitLab CI, Jenkins, CircleCI |
| Registro de imágenes | Docker Hub, AWS ECR, GCP Artifact Registry, Azure ACR |
| Orquestador | Kubernetes, Docker Swarm, ECS, Nomad |
| Monitorización | Prometheus, Grafana, Datadog, New Relic |

> 💡 **Nota:** los nombres de las herramientas cambian, pero el **patrón es el mismo**: código → build → imagen → registro → despliegue.

---

### ¿Qué herramientas se usan a nivel industrial sin excepción?

**Ninguna.** Cada empresa elige su stack según sus necesidades, presupuesto, expertise y contexto. Sin embargo, el **concepto de pipeline CI/CD** y el uso de **imágenes Docker** se han vuelto estándar en la industria moderna.

**Ejemplos de variaciones:**
- GitHub vs GitLab vs Bitbucket
- Docker Hub vs ECR vs GCR vs ACR
- Kubernetes vs Docker Swarm vs ECS vs Nomad
- GitHub Actions vs Jenkins vs CircleCI vs GitLab CI

> 🧠 **Conclusión:** No hay una herramienta universal, pero el **flujo de trabajo basado en imágenes Docker** sí lo es. El proceso siempre implica: construir, versionar, registrar y desplegar contenedores.
