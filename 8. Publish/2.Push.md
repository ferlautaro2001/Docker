## Publicando en Docker Hub

Después de construir mi imagen de Go, la voy a subir a Docker Hub para compartirla o simplemente para tenerla disponible en la nube. El proceso requiere:

1. Recompilar el binario para Linux.
2. Construir la imagen con un nombre que incluya mi usuario de Docker Hub.
3. Hacer `docker push` para subirla.

---

### 1. Recompilar el binario para Linux

```bash
GOOS=linux GOARCH=amd64 go build -o goserver
```

> 📝 **Explicación:** el contenedor corre sobre Linux, así que necesito un binario compatible con `linux/amd64`.

---

### 2. Construir la imagen con el nombre correcto

```bash
docker build . -t tu-usuario/goserver
```

**Salida esperada:**
```
[+] Building 0.3s (6/6) FINISHED
 => [1/2] FROM docker.io/library/debian:stable-slim
 => [2/2] COPY goserver /bin/goserver
 => exporting to image
 => => naming to docker.io/tu-usuario/goserver:latest
```

> 💡 **Nota:** reemplazo `tu-usuario` por mi nombre de usuario en Docker Hub (ej. `johndoe/goserver`).

---

### 3. Probar la imagen localmente

```bash
docker run -p 8991:8991 tu-usuario/goserver
```

**Salida esperada:**
```
server started on 8991
```

> ✅ **Verificación:** si responde en `http://localhost:8991`, la imagen funciona correctamente.

---

### 4. Subir la imagen a Docker Hub

```bash
docker push tu-usuario/goserver
```

**Salida esperada:**
```
Using default tag: latest
The push refers to repository [docker.io/tu-usuario/goserver]
2f3a4b5c6d7e: Pushed 
3a4b5c6d7e8f: Pushed 
latest: digest: sha256:2f3a4b5c6d7e... size: 1234
```

> 📤 **Nota:** `docker push` sube las capas de la imagen al registro. La primera vez puede tardar unos segundos.

---

### 5. Verificar en Docker Hub

Abro mi perfil en Docker Hub: https://hub.docker.com/u/tu-usuario

**Debería ver el repositorio `goserver` en la lista.**

> 🌐 **Nota:** por defecto, las imágenes subidas son **públicas**, lo que significa que cualquier persona puede descargarlas con `docker pull tu-usuario/goserver`.

---

### 6. Probar la imagen desde Docker Hub

```bash
docker pull tu-usuario/goserver
docker run -p 8991:8991 tu-usuario/goserver
```

> 🚀 **Conclusión:** ahora mi imagen está disponible en la nube y puedo ejecutarla desde cualquier máquina con Docker.

---

### Comandos relacionados

| Comando | Descripción |
|---------|-------------|
| `docker login` | Iniciar sesión en Docker Hub |
| `docker build -t USERNAME/IMAGE .` | Construir imagen con nombre para Docker Hub |
| `docker push USERNAME/IMAGE` | Subir la imagen a Docker Hub |
| `docker pull USERNAME/IMAGE` | Descargar la imagen desde Docker Hub |
