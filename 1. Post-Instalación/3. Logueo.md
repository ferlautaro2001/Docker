
## `docker login`

`docker login` me autentica en un registro de contenedores (por defecto Docker Hub) desde mi terminal, vinculando mi cliente local con mi cuenta de Docker Hub. Esto es necesario para poder subir (push) imágenes a mi repositorio personal o a organizaciones, y también para acceder a imágenes privadas.

El comando me pide usuario y contraseña (o token de acceso) si no uso las credenciales inline. Pero si ya estoy logueado desde Docker Desktop, el CLI ya tiene las credenciales guardadas y el comando no muestra nada, simplemente sale con código 0 (éxito). Esa es la forma más limpia de hacerlo.

**Ejemplo de comando:**
```bash
docker login
```

**Salida esperada si ya estoy logueado desde Docker Desktop:**
```bash
Authenticating with existing credentials...
Login Succeeded
```

**Salida esperada si NO estoy logueado previamente (interactivo):**
```bash
Log in with your Docker ID or email address to push/pull images from Docker Hub.
Username: mi_usuario
Password: 
Login Succeeded
```

> 🔐 **Tip:** si usás un token de acceso en vez de la contraseña (más seguro), lo pegas en el prompt de password. También podés hacer login pasando usuario directamente: `docker login -u mi_usuario` y te pedirá solo la contraseña/token.
