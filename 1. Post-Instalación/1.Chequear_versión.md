## `docker version`

El comando `docker version` muestra información detallada sobre las versiones del cliente (CLI) y del servidor (Docker Daemon) que están instalados y comunicándose en el sistema. 

La salida esperada se divide en dos secciones principales:

- **`Client:`** — Muestra la versión del CLI de Docker que estás ejecutando, la arquitectura (ej. `linux/amd64`), el sistema operativo y el contexto actual (por defecto `default`).
- **`Server:`** — Muestra la versión del Docker Daemon al que el cliente se está conectando, incluyendo la versión del motor (*Engine*), la API, el sistema operativo del host y el kernel.

Ambas secciones deben aparecer para confirmar que Docker está correctamente instalado, que el daemon está ejecutándose y que el cliente puede comunicarse con él.
