## Configurando el puerto con variables de entorno

Una de las grandes ventajas de Docker es poder **configurar el entorno** de la aplicación mediante variables de entorno. En esta lección voy a modificar mi servidor Go para que el puerto sea configurable mediante la variable `PORT`.

---

### 1. Modificar `main.go` para leer `PORT` desde el entorno

```go
package main

import (
	"fmt"
	"log"
	"net/http"
	"os"  // ← importo el paquete os
	"time"
)

func main() {
	m := http.NewServeMux()

	m.HandleFunc("/", handlePage)

	port := os.Getenv("PORT")  // ← leo la variable de entorno
	if port == "" {
		port = "8010"  // ← valor por defecto si no está definida
	}

	srv := http.Server{
		Handler:      m,
		Addr:         ":" + port,
		WriteTimeout: 30 * time.Second,
		ReadTimeout:  30 * time.Second,
	}

	fmt.Println("server started on", port)
	err := srv.ListenAndServe()
	log.Fatal(err)
}

func handlePage(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/html")
	w.WriteHeader(200)
	const page = `<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
`
	w.Write([]byte(page))
}
```

> 📝 **Cambios clave:**
> - `import "os"` — agrego el paquete para leer variables de entorno.
> - `port := os.Getenv("PORT")` — leo la variable `PORT`.
> - Si `PORT` no está definida, uso `"8010"` como valor por defecto.

---

### 2. Probar localmente con variable de entorno

```bash
export PORT="8999"
go build -o goserver
./goserver
```

**Salida esperada:**
```
server started on 8999
```

> 📝 **Nota:** el servidor ahora escucha en el puerto 8999.

---

### 3. Probar con `curl`

```bash
curl http://localhost:8999/
```

**Salida esperada:**
```html
<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
```

> ✅ **Funciona!** El servidor responde en el puerto configurado.

---

### 4. Detener el servidor

Presiono `Ctrl+C` para detener el servidor local.

---

### 5. Modificar el `Dockerfile`

Agrego `ENV PORT=8991` para establecer la variable de entorno dentro de la imagen:

```dockerfile
FROM debian:stable-slim

COPY goserver /bin/goserver

ENV PORT=8991

CMD ["/bin/goserver"]
```

> 📝 **Nota:** `ENV` establece la variable de entorno dentro del contenedor. Esta estará disponible cuando el servidor arranque.

---

### 6. Recompilar el binario para Linux (si no estoy en Linux)

```bash
GOOS=linux GOARCH=amd64 go build -o goserver
```

---

### 7. Reconstruir la imagen Docker

```bash
docker build . -t goserver:latest
```

**Salida esperada:**
```
[+] Building 0.3s (6/6) FINISHED
 => [1/2] FROM docker.io/library/debian:stable-slim
 => [2/2] COPY goserver /bin/goserver
 => exporting to image
 => => naming to docker.io/library/goserver:latest
```

---

### 8. Ejecutar el contenedor

```bash
docker run -p 8991:8991 goserver
```

**Salida esperada:**
```
server started on 8991
```

> 📝 **Nota:** el servidor dentro del contenedor escucha en el puerto 8991 (definido por `ENV` en el `Dockerfile`).

---

### 9. Probar el servidor desde el host

```bash
curl http://localhost:8991/
```

**Salida esperada:**
```html
<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
```

> ✅ **¡Funciona!** El contenedor responde en el puerto configurado por `ENV`.

---

### 10. Probar en el navegador

Abro `http://localhost:8991/` en el navegador. Debería ver:

```
Hello from Docker! I'm a Go server.
```

---

### 11. Detener el contenedor

Presiono `Ctrl+C` en la terminal donde está corriendo el contenedor.

**Pasos para la lección (resumen):**
1. Modifico `main.go` para leer `PORT` con `os.Getenv()`.
2. `export PORT="8999"` y corro el servidor local para probar.
3. Agrego `ENV PORT=8991` al `Dockerfile`.
4. Recompilo el binario para Linux: `GOOS=linux GOARCH=amd64 go build -o goserver`.
5. `docker build . -t goserver:latest` — construyo la imagen.
6. `docker run -p 8991:8991 goserver` — ejecuto el contenedor.
7. `curl http://localhost:8991/` — verifico que responde.
8. `Ctrl+C` — detengo el contenedor.
