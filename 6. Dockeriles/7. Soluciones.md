## Dockerizando Python (con el intérprete instalado)

En la lección anterior, el contenedor falló porque la imagen base `debian:stable-slim` no tenía Python instalado. Ahora voy a arreglarlo agregando un comando `RUN` que instale Python dentro de la imagen.

---

### 1. Actualizar el `Dockerfile.py`

Modifico el archivo para que instale Python antes de ejecutar el script:

```dockerfile
FROM debian:stable-slim

# Instalo Python 3 y pip
RUN apt-get update && apt-get install -y python3

COPY main.py main.py
COPY books/ books/

CMD ["python3", "main.py"]
```

> 📝 **Explicación:**
> - `RUN apt-get update && apt-get install -y python3` — actualiza los repositorios e instala Python 3.
> - `CMD ["python3", "main.py"]` — ejecuta el script con `python3` (no con `python`).

> ⚠️ **Nota:** uso `python3` en lugar de `python` porque en Debian el comando `python` no existe por defecto (sí existe `python3`).

---

### 2. Construir la imagen

```bash
docker build -t bookbot -f Dockerfile.py .
```

**Salida esperada:**
```

 => [1/4] FROM docker.io/library/debian:stable-slim
 => [2/4] RUN apt-get update && apt-get install -y python3
 => => # Get:1 http://deb.debian.org/debian stable InRelease [123 kB]
 => => # Get:2 http://deb.debian.org/debian stable-updates InRelease [52.1 kB]
 => => # ...
 => [3/4] COPY main.py main.py
 => [4/4] COPY books/ books/

 => => naming to docker.io/library/bookbot:latest
```

> ⏱️ **Nota:** la instalación de Python puede tomar varios minutos (depende de la conexión a internet).

---

### 3. Ejecutar el contenedor

```bash
docker run bookbot
```

**Salida esperada:**
```
--- Begin report of books/frankenstein.txt ---
77986 words found in the document

The 'e' character was found 46043 times
The 't' character was found 30365 times
The 'a' character was found 26743 times
...
--- End report ---
```

> ✅ **¡Funciona!** El contenedor ejecuta el script de Python correctamente.

---

### 4. Verificar que el contenedor terminó

```bash
docker ps -a
```

**Salida esperada:**
```
CONTAINER ID   IMAGE      COMMAND              CREATED         STATUS                     PORTS     NAMES
4a5b6c7d8e9f   bookbot    "python3 main.py"    2 minutes ago   Exited (0) 1 minute ago              happy_fermat
```

> 📋 **Nota:** `STATUS` muestra `Exited (0)`, indicando que el script terminó correctamente.

---

### ¿Por qué esta vez funcionó?

| Componente | Presente en Debian slim | Necesario para Python |
|------------|------------------------|-----------------------|
| Debian OS  | ✅ Sí                  | ✅ Sí                 |
| Python     | ❌ No → ✅ **Sí**      | ✅ Sí                 |
| Script     | ✅ Sí                  | ✅ Sí                 |
| Libro      | ✅ Sí                  | ✅ Sí                 |

> 🧠 **Conclusión:** para que un contenedor funcione, no basta con copiar el código. Hay que instalar todas las dependencias del entorno de ejecución, en este caso, el intérprete de Python.

---

### Comparación con Go

| Lenguaje | Tamaño de imagen | Tiempo de build | Dependencias |
|----------|------------------|-----------------|--------------|
| Go       | ~55 MB (Debian slim + binario) | Rápido | Solo el binario |
| Python   | ~150 MB (Debian slim + Python) | Más lento | Intérprete + dependencias |

> 💡 **Nota:** por eso es común usar imágenes oficiales como `python:3.10-slim` que ya vienen con Python preinstalado, ahorrando tiempo de build y simplificando el `Dockerfile`.


**Pasos para la lección (resumen):**
1. Modifico `Dockerfile.py` agregando `RUN apt-get update && apt-get install -y python3`.
2. `docker build -t bookbot -f Dockerfile.py .` — construyo la imagen.
3. `docker run bookbot` — ejecuto el contenedor y veo el informe del libro.
