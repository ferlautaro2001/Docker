## Dockerizando un script en Python

Los programas en Go compilan a un binario que incluye todo lo necesario para ejecutarse. Pero los lenguajes como **Python** necesitan el intérprete y las dependencias instaladas en el sistema donde se ejecutan. Docker es ideal para empaquetar todo ese entorno junto con el código.

En esta lección voy a Dockerizar un script Python que cuenta palabras y caracteres en un libro.

---

### 1. Crear el archivo `main.py`

En mi directorio de trabajo creo un archivo `main.py` con el código del script:

```python
def main():
    book_path = "books/frankenstein.txt"
    text = get_book_text(book_path)
    num_words = get_num_words(text)
    chars_dict = get_chars_dict(text)
    chars_sorted_list = chars_dict_to_sorted_list(chars_dict)

    print(f"--- Begin report of {book_path} ---")
    print(f"{num_words} words found in the document")
    print()

    for item in chars_sorted_list:
        if not item["char"].isalpha():
            continue
        print(f"The '{item['char']}' character was found {item['num']} times")

    print("--- End report ---")


def get_num_words(text):
    words = text.split()
    return len(words)


def sort_on(d):
    return d["num"]


def chars_dict_to_sorted_list(num_chars_dict):
    sorted_list = []
    for ch in num_chars_dict:
        sorted_list.append({"char": ch, "num": num_chars_dict[ch]})
    sorted_list.sort(reverse=True, key=sort_on)
    return sorted_list


def get_chars_dict(text):
    chars = {}
    for c in text:
        lowered = c.lower()
        if lowered in chars:
            chars[lowered] += 1
        else:
            chars[lowered] = 1
    return chars


def get_book_text(path):
    with open(path) as f:
        return f.read()


main()
```

### 2. Crear la estructura de directorios

```bash
mkdir -p books
curl -o books/frankenstein.txt https://raw.githubusercontent.com/bootdotdev/fcc-book-tutorial/main/books/frankenstein.txt
```

> 📂 **Nota:** el script espera que el archivo esté en `books/frankenstein.txt` (relativo al directorio donde se ejecuta).

---

### 3. Probar que el script funciona localmente

```bash
python3 main.py
```

**Salida esperada:**
```

The 'e' character was found 46043 times
The 't' character was found 30365 times
The 'a' character was found 26743 times
...
--- End report ---
```

> ✅ **¡Funciona!** El script analiza el texto y genera el informe.

---

### 4. Crear el `Dockerfile`

Creo un archivo `Dockerfile` en el directorio raíz:

```dockerfile
# Usa la imagen oficial de Python 3.10+
FROM python:3.10-slim

# Copia el código y el libro al contenedor
COPY main.py /app/main.py
COPY books /app/books

# Define el directorio de trabajo
WORKDIR /app

# Ejecuta el script
CMD ["python", "main.py"]
```

> 📝 **Explicación línea por línea:**
> - `FROM python:3.10-slim` — imagen base con Python 3.10 en una versión liviana.
> - `COPY main.py /app/main.py` — copio el script al contenedor.
> - `COPY books /app/books` — copio la carpeta de libros.
> - `WORKDIR /app` — establezco el directorio de trabajo.
> - `CMD ["python", "main.py"]` — ejecuto el script al arrancar el contenedor.

---

### 5. Construir la imagen Docker

```bash
docker build . -t python-stats:latest
```

### ¿Por qué Dockerizar Python?

- **Consistencia** — el mismo entorno (versión de Python, dependencias) en cualquier máquina.
- **Aislamiento** — no afecta al sistema host.
- **Portabilidad** — se puede ejecutar en cualquier lugar que tenga Docker.
- **Reproducibilidad** — el `Dockerfile` documenta exactamente cómo se construye el entorno.

> 🧠 **Conclusión:** Docker no solo sirve para servidores web; también es útil para scripts, herramientas de análisis, procesamiento de datos, y cualquier aplicación que necesite un entorno específico.
