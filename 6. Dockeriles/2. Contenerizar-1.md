## Construyendo un servidor web en Go

Antes de meter el servidor en Docker, primero lo construyo y ejecuto en mi máquina local. Esto asegura que el código funciona antes de contenerizarlo. El servidor es simple: responde con un mensaje HTML en `localhost:8010`.

---

### 1. Crear el archivo `main.go`

En mi directorio de trabajo (`goserver/`) creo un archivo `main.go` con el código del servidor:

```go
package main

import (
	"fmt"
	"log"
	"net/http"
	"time"
)

func main() {
	m := http.NewServeMux()

	m.HandleFunc("/", handlePage)

	const port = "8010"
	srv := http.Server{
		Handler:      m,
		Addr:         ":" + port,
		WriteTimeout: 30 * time.Second,
		ReadTimeout:  30 * time.Second,
	}

	// esto bloquea hasta que el servidor tenga un error irrecuperable
	fmt.Println("server started on", port)
	err := srv.ListenAndServe()
	log.Fatal(err)
}

func handlePage(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/html")
	w.WriteHeader(200)
	const page = `<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
`
	w.Write([]byte(page))
}
```

> 📝 **¿Qué hace el código?**
> - Crea un servidor HTTP en el puerto 8010.
> - Responde a cualquier ruta (`/`) con un mensaje HTML.
> - El servidor se ejecuta hasta que reciba una señal de interrupción (Ctrl+C).

---

### 2. Inicializar el módulo Go

```bash
go mod init github.com/mi-usuario/goserver
```

**Salida esperada:**
```
go: creating new go.mod: module github.com/mi-usuario/goserver
go: to add module requirements and sums:
	go mod tidy
```

> 💡 **Nota:** reemplazo `mi-usuario` con mi nombre de usuario de GitHub y `goserver` con el nombre de mi proyecto.

---

### 3. Descargar dependencias (si es necesario)

```bash
go mod tidy
```

**Salida esperada:** no hay salida (o descarga dependencias automáticas).

---

### 4. Construir el binario

```bash
go build -o goserver
```

**Salida esperada:** se crea el binario `goserver` en el directorio actual.

> 📦 **Nota:** `-o goserver` especifica el nombre del archivo binario de salida. Si no se usa, el binario se llama igual que el directorio.

---

### 5. Ejecutar el servidor

```bash
./goserver
```

**Salida esperada:**
```
server started on 8010
```

El servidor se queda ejecutando y bloquea la terminal.

---

### 6. Probar el servidor

En otra terminal, o usando `curl`, accedo a `http://localhost:8010`:

```bash
curl http://localhost:8010/
```

**Salida esperada:**
```html
<html>
<head></head>
<body>
	<p> Hello from Docker! I'm a Go server. </p>
</body>
</html>
```

> ✅ **¡Funciona!** El servidor responde con el mensaje HTML.

---

### 7. Probar con el navegador

Abro `http://localhost:8010/` en mi navegador. Debería ver:

```
Hello from Docker! I'm a Go server.
```

---

### 8. Detener el servidor

Vuelvo a la terminal donde está corriendo el servidor y presiono `Ctrl+C` para detenerlo.

**Salida esperada:**
```
^C
```

> 🛑 **Nota:** el servidor se detiene y vuelvo al prompt de la terminal.

**Pasos para la lección (resumen):**
1. Creo `main.go` con el código del servidor.
2. `go mod init github.com/mi-usuario/goserver` — inicializo el módulo.
3. `go build -o goserver` — compilo el binario.
4. `./goserver` — ejecuto el servidor.
5. `curl http://localhost:8010/` — verifico que responde.
6. `Ctrl+C` — detengo el servidor.
