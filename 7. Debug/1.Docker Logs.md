## `docker logs`

Cuando los contenedores corren en modo `-d` (detached), no veo la salida en mi terminal. `docker logs` me permite ver la salida estándar (stdout) y de error (stderr) de un contenedor en ejecución o detenido. Es como `tail -f` para un contenedor.

---

### 1. Ejecutar un contenedor que genera logs

```bash
docker run -d --name logdate alpine sh -c 'while true; do echo "LOGGING: $(date)"; sleep 1; done'
```

**Salida esperada:**
```
2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f
```

> 📝 **Explicación del comando:**
> - `alpine` — imagen base liviana de Linux.
> - `sh -c 'while true; do echo "LOGGING: $(date)"; sleep 1; done'` — script simple que imprime la fecha cada segundo.

---

### 2. Ver el ID del contenedor

```bash
docker ps
```

**Salida esperada:**
```
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS     NAMES
2f3a4b5c6d7e   alpine    "sh -c 'while true; …"   5 seconds ago   Up 4 seconds             logdate
```

---

### 3. Ver los logs del contenedor

```bash
docker logs 2f3a4b5c6d7e
```

**Salida esperada:**
```
LOGGING: Mon Jan 15 10:30:01 UTC 2024
LOGGING: Mon Jan 15 10:30:02 UTC 2024
LOGGING: Mon Jan 15 10:30:03 UTC 2024
LOGGING: Mon Jan 15 10:30:04 UTC 2024
LOGGING: Mon Jan 15 10:30:05 UTC 2024
...
```

> 📋 **Nota:** `docker logs` muestra los logs desde que el contenedor arrancó hasta el momento actual.

---

### 4. Seguir los logs en tiempo real (`-f`)

```bash
docker logs -f 2f3a4b5c6d7e
```

**Salida esperada:**
```
LOGGING: Mon Jan 15 10:30:06 UTC 2024
LOGGING: Mon Jan 15 10:30:07 UTC 2024
LOGGING: Mon Jan 15 10:30:08 UTC 2024
...
```

> 🖥️ **Nota:** el comando se queda ejecutando, mostrando nuevos logs en tiempo real (como `tail -f`).

---

### 5. Salir del modo seguimiento

Presiono `Ctrl+C` para salir del modo `-f`.

---

### 6. Ver solo los últimos 5 logs

```bash
docker logs --tail 5 2f3a4b5c6d7e
```

**Salida esperada:**
```
LOGGING: Mon Jan 15 10:30:20 UTC 2024
LOGGING: Mon Jan 15 10:30:21 UTC 2024
LOGGING: Mon Jan 15 10:30:22 UTC 2024
LOGGING: Mon Jan 15 10:30:23 UTC 2024
LOGGING: Mon Jan 15 10:30:24 UTC 2024
```

> 📋 **Nota:** `--tail 5` muestra solo las últimas 5 líneas.

---

### 7. Detener y eliminar el contenedor

```bash
docker stop logdate
docker rm logdate
```

**Salida esperada:**
```
logdate
logdate
```

---

### Opciones útiles de `docker logs`

| Opción | Descripción |
|--------|-------------|
| `-f` | Seguir los logs en tiempo real |
| `--tail N` | Mostrar solo las últimas N líneas |
| `--since 1h` | Mostrar logs de la última hora |
| `--until 2024-01-15T10:00:00Z` | Mostrar logs hasta una fecha específica |
| `-t` | Mostrar timestamps en los logs |

> 🧠 **Conclusión:** `docker logs` es la herramienta principal para depurar contenedores. Es como leer los logs de cualquier servicio, pero centralizado a través del CLI de Docker.

**Pasos para la lección (resumen):**
1. `docker run -d --name logdate alpine sh -c 'while true; do echo "LOGGING: $(date)"; sleep 1; done'` — arranco un contenedor que genera logs.
2. `docker ps` — obtengo el ID del contenedor.
3. `docker logs <ID>` — veo los logs del contenedor.
4. `docker logs -f <ID>` — sigo los logs en tiempo real.
5. `Ctrl+C` — salgo del modo seguimiento.
6. `docker logs --tail 5 <ID>` — veo solo los últimos 5 logs.
7. `docker stop logdate && docker rm logdate` — detengo y elimino el contenedor.
